## FourSeas

FourSeas is a 4-oscillator wavetable synthesizer Eurorack module by Ferry Island Modular. It supports control over I2C (ii) at address `0x58`, allowing Teletype to offset wavetable positions, pitch, spreads, modulation depths, bank selection, and per-oscillator parameters. All parameters are additive with the module's knob and CV positions. For more information: https://github.com/ferryislandmodular/fourseas
